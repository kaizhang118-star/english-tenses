# 英语时态速查（网页版）

一个**单文件、零依赖、可离线**的英语时态查询工具，专为手机和微信内打开设计。整个工具就是一个 `index.html`，没有后端、不请求任何外部资源。

## 它解决什么

原 `english-tenses` 技能只能在这台电脑上通过 Codex 调用。这个网页版把它搬到任何能上网的设备上：微信里点开链接就能查，不需要这台电脑开机。

## 怎么用

- 打开后是时间轴和时态列表，点任意一项看构成、标志词、例句、易错点。
- 顶部搜索框支持搜时态名、标志词、口诀、术语和例句，例如「现在完成时」「标志词」「直去双改特」「when」「for」。
- 详情页右上角「复制全文」把整节内容复制成纯文本，可直接粘到微信聊天里。
- 链接可带关键词直达结果：`index.html?q=现在完成时`，可以把这类链接存进微信收藏或发给「文件传输助手」。
- 章节可直达：`index.html#ch06`。

## 放到手机上用（三种方式）

### 1. 免费静态托管（推荐）

不需要买服务器，把整个文件夹拖到任意静态托管即可，几分钟拿到一个 https 链接：

- **Netlify Drop**：打开 `app.netlify.com/drop`，把 `english-tenses-web` 文件夹拖进去，立即得到网址。
- **Cloudflare Pages**：控制台 → Workers & Pages → Create → Pages → Upload assets，上传该文件夹。
- **GitHub Pages**：新建仓库 → 上传 `index.html` → Settings → Pages → 选 main 分支根目录。

拿到网址后，在微信里发给自己（文件传输助手）或存进「收藏」，以后随时点开。

### 2. 自己的服务器 / 对象存储

把 `index.html` 放到任意 web 目录、OSS/COS 静态网站、或者 NAS 上，直接访问即可。没有构建步骤，不需要 Node、Python 或数据库。

### 3. 完全不联网

把 `index.html` 通过微信发到「文件传输助手」，在手机上用**系统浏览器**打开（微信内置浏览器对本地 .html 文件支持不稳定）。离线可用，但每次都要先找到这个文件，适合应急。

## 微信里查 vs 微信里问

这个工具是**打开链接查**，不是**在聊天窗口里问**。两者区别：

| | 本工具（静态网页） | 聊天式问答机器人 |
|---|---|---|
| 需要服务器 | 不需要 | 需要（常开） |
| 需要注册公众号 | 不需要 | 需要 |
| 成本 | 0 元 | 服务器费用 |
| 微信里的形态 | 点链接打开页面 | 直接发消息给公众号/机器人 |
| 离线可用 | 可以 | 不可以 |

如果以后要「在聊天窗口里直接问」，那需要注册一个微信公众号（或企业微信应用），再把同一个知识库挂到一个常开的服务器上做消息回调——这一步需要账号和服务器，与当前工具不冲突，可以在这份数据基础上继续做。

## 内容范围

覆盖 7 个时态 + 2 个专题：现在进行时、一般将来时（shall / will / be going to）、had better、一般现在时、一般过去时、现在完成时、过去进行时、瞬间动词与延续性动词 · when vs while。

**未包含**：过去完成时、过去将来时、各种完成进行时。原笔记「过去进行时 → when 的用法」一节为空，网页版已在对应章节标明并给出补足来源。

## 版权提示

内容整理自一份第三方中文语法笔记（有道笔记导出）。作为个人学习工具自用没问题；如果要放到公开可检索的网址上传播，建议使用未公开的链接，或选择需要登录/密码的托管方式，避免公开再分发他人整理的资料。

## 怎么更新内容

所有知识点都在 `index.html` 底部的 `<script type="application/json" id="kb">` 里，是纯 JSON：

- `tenses`：8 个时态/专题，含 `tables`（构成表）、`bullets`（要点）、`markers`（标志词）、`examples`（例句）、`pitfalls`（易错点）、`key`（先记住）、`links`（相关章节）。
- `cheats`：速查表（决策、标志词对照、五个口诀、句式改造、易错点、变化规则）。
- `terms`：术语表，第三项是关联章节 id。

改完保存，刷新页面即可生效。

## 自检

在网址后加 `?debug=1` 会输出一段布局自检数据（视口宽度、是否有元素溢出、各区块元素数量），用于确认改版后没有撑破手机屏幕。
